新增管理界面：用户管理 + IP 黑白名单

管理界面
- 入口 /view/admin，需 rw 权限账号登录（默认 admin/admin）
- 用户管理：增删改用户、设置 r/rw 权限、口令可明文或 sha256
- IP 访问控制：启用开关 + 白名单 + 黑名单，每行一条规则
- 保存即写回 config.json 并热重载，无需重启

IP 规则（app/iprules.py）
- 支持单 IP、CIDR(192.168.2.0/24)、区间(192.168.2.100-192.168.2.150
  及缩写 192.168.2.100-150)、通配符(192.168.2.*)、全部(*)、IPv6
- 黑名单优先；白名单非空时仅放行命中白名单的 IP
- 规则同时作用于 HTTP / WebDAV / FTP

统一准入控制（app/access.py）
- 三协议共享同一 AccessController，规则只有一份
- reload() 热重载配置；FTP 授权器缓存按代际失效

安全设计
- /view/admin 与 /api/admin/* 不受 IP 黑白名单限制（另有管理员鉴权），
  避免规则配错后把自己锁在门外无法修正

验证
- 源码 + 打包 exe 双验证：管理页 200、状态/增删改用户、IP 规则启停、
  白名单放行、黑名单优先、三协议拦截、FTP 用户热重载（新增即用/删除即拒）
